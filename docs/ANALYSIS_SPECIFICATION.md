Date: 2026-09-26. Hypotheses and thresholds in the research plan remain unchanged.

- Analyze the entire configured grid; reject incomplete or duplicate tables. Separate the archived, incompatible v1 smoke results.
- Resample seeds, never treat epsilon rows or grid cells as independent replicates. Report 95% percentile bootstrap intervals (5,000 draws, fixed RNG seed). With three seeds, these are coarse descriptive intervals, not strong population evidence.
- H1: within each dataset and seed, calculate variance–noise Spearman correlations at fixed repetitions/bandwidth and variance–depth correlations at fixed noise/bandwidth. Summarize each axis by its median stratum correlation. Require both axes <= -0.7 in >=80% of dataset–seed groups. Publish all strata, so aggregation choices are visible.
- H2: calculate Spearman and partial Spearman using one row per model, with clean accuracy as the primary control and repetitions/noise as additional sensitivity controls. Report the A0 association explicitly as a linearized proxy. Compare A0 against the smallest successful tested A2 epsilon for the first 20 initially correct points, selected by original test ordering. Retain right-censoring at the maximum tested budget. A0 is not a certified margin; coarse PGD-grid upper bounds do not establish the prespecified strong-attack margin hypothesis. Mark H2 inconclusive if the available measurements cannot establish that criterion.
- H3: report signed A1-minus-A2 gaps and their seed bootstrap intervals for each dataset/repetitions/bandwidth/noise/epsilon stratum. "Consistent across seeds" means gap >0.05 for every configured seed in at least one nonzero-noise stratum. Use paired Wilcoxon tests and BH-adjusted p-values across these comparisons. M1/M2/M4/M5 flags remain visible; M3 is untested, so absence of masking cannot be established.
- H4: supplement the noiseless family with c=0.1,0.25,2.0 (Phase 6's planned iso-concentration experiment, not Tier B). Keep repetitions/dataset/seed fixed and interpolate each family's outcome against log10 variance only in their common range. Exclude the shared c=1,p=0 anchor from claims of independent agreement. Report overlap widths and seed-wise mean curve differences on a common interior grid. No extrapolation. Separation with intervals excluding zero is evidence against H4; intervals including zero are inconclusive without a prespecified equivalence tolerance. Do not equate failure to reject with a causal mechanism.
- H5: RBF gamma is matched using training-kernel variance alone. If two roots exist, choose the smaller gamma deterministically; log both root count and achieved residual. Accept variance matching only at <=1% relative error. Define matched clean accuracy descriptively as absolute test-accuracy difference <=0.03; this filters comparisons, never tunes a model. Report how many comparisons remain. Require the entire seed-bootstrap interval of the paired robust-accuracy difference to lie in [-0.03,0.03] for equivalence; publish each eligible stratum. Do not infer equivalence from a nonsignificant difference.
- Report all diagnostics and limitations. No test-data hyperparameter optimization; no Tier B/C or black-box experiment is added.
